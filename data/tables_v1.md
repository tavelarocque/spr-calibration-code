# Exact SPR values, v1 (Rust solver)

Produced by `spr tabulate` (crates/spr-cli) with one shared transposition table per
variant, monotone bounds on, u64 boards. Every value is an exact integer. Rows n,
columns s = 1..2n; no row was cut short at a plateau. Validation and methods are in
the write-up (in preparation). Per-cell state counts, Pointer-node counts and timings are in
data/values_{full,forced,qv}_v1.csv.

The `states` column is the size of the shared table after the row, cumulative over all
earlier rows. `nodes` counts Pointer-node visits during the row. Timings marked `*` were
affected by swap pressure: more than 32768 pages (16 KiB each, about 0.5 GiB) were
swapped out system-wide while the row ran. Swap affects only the timings, never the values.
